## Technical Stack & Architecture

- **Engine**: React 19 + TypeScript + Vite 8
- **3D Interactive Graphics**: Three.js WebGL (Interactive BGA Silicon Processor Die & Dynamic Cybernetic Constellation background)
- **Design System & Styling**: Tailwind CSS v4 + Obsidian Luxury Theme
- **Vector Iconography**: Lucide React
- **Deployment**: GitHub Pages automated via GitHub Actions (`.github/workflows/deploy.yml`)

---

## Core Portal Modules

1. **Precision 3D Hero Visualizer**: Interactive 3D silicon processor die rendered with Three.js with mouse-rotation tracking and active diagnostic HUD.
2. **Dynamic 3D Constellation Background**: Hardware motherboard nodes connected with subtle laser lines responding to user cursor physics.
3. **Engineering Disciplines (Services)**:
   - BGA Chip-Level Motherboard Diagnostics & Micro-Soldering
   - Dedicated VGA & GPU Reflow & Reballing Solutions
   - Apple MacBook Logic Board Architecture (Apple Silicon & Intel)
   - Enterprise Laptop & Desktop Model Overhauls (Dell, HP, Lenovo, ASUS, Acer, HCL)
   - Mobile Micro-Electronics & Board-Level Jumper Wiring
   - High-Speed SPI BIOS EEPROM Programming & Data Integrity
4. **Interactive Triage & Diagnostic Matrix**: Clients can select their platform and observed symptoms to preview estimated bench time, suspected root causes, and launch a pre-formatted WhatsApp consultation to Natvar Ji with 1 click.
5. **OEM Ecosystem**: Full coverage for MacBook, Dell, Lenovo, HP, ASUS, Acer, HCL.
6. **Laboratory Bench Standards**: Explaining FLIR thermal profiling, infrared multi-zone BGA station, and stereoscopic optical magnification.
7. **Direct Hardware Dispatcher**: Walk-in location details, Google Map embed at Chandani Chowk Metro Gate 6, and direct WhatsApp dispatch form.

## Local Development

```bash
# Clone the repository
git clone https://github.com/debajoyti007-max/siddhi-infotech.git
cd siddhi-infotech

# Install dependencies
npm install --legacy-peer-deps

# Start Vite development server
npm run dev

# Build for production
npm run build
```
